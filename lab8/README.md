# Лабораторная работа №8: CRUD-сервис для пространственной базы данных

## Описание
CRUD-сервис на FastAPI для работы с территориями и их показателями.

## Функциональность
- Создание, чтение, обновление, удаление территорий
- Создание, чтение, обновление, удаление показателей территорий
- Автоматическая документация API (Swagger UI)

## Запуск
```bash
cd lab8
uvicorn app.main:app --reload
Swagger UI: http://localhost:8000/docs
## Примечание
