## Лабораторная работа №5: FastAPI конфигурация

### Результаты тестирования

| Эндпоинт | Результат |
|----------|-----------|
| `GET /health` |  `{"status": "ok"}` |
| `GET /config/app` | Возвращает название, версию, описание, авторов |
| `GET /config/runtime` | Возвращает динамические настройки |
| `PUT /config/runtime` | Обновляет настройки без перезапуска |

### Демонстрация работы

1. Запуск сервера: `uvicorn main:app --reload`
2. Статическая конфигурация (меняется только при перезапуске):
   - Название: Laboratory FastAPI App
   - Версия: 1.0.0
3. Динамическая конфигурация (обновляется через API):
   - Было: `log_level: INFO`, `maintenance_mode: false`
   - Стало: `log_level: DEBUG`, `maintenance_mode: true`

**Вывод:** Приложение успешно разделяет статическую и динамическую конфигурацию.
